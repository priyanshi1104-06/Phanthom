# Phantom brand

Obsidian & Gold: a gold half-mask on black. One half is the mask, with the eye cut out; the other half of
the face is a dashed line: the part you can't see, which is what Phantom finds.

| File | Use |
|---|---|
| `phantom-icon.svg`, `phantom-icon-512.png`, `phantom-icon-128.png` | app icon, VS Code Marketplace icon (`extension/media/icon.png`) |
| `favicon-32.png`, `favicon-16.png` | website favicon |
| `phantom-mark-gold.svg` | the mark alone, gold, transparent background |
| `phantom-mark-mono.svg` | single colour: VS Code activity bar (`extension/media/phantom.svg`), print |
| `phantom-logo-dark.svg` / `.png` | mark + wordmark on dark backgrounds |
| `phantom-logo-light.svg` / `.png` | mark + wordmark on light backgrounds |
| `phantom-logo-full-dark.png`, `phantom-logo-full-light.png` | full-size lockups, 3200 x 1200, wordmark PHANTOM.AI (".AI" in gold) in real Inter: website, slides, press |
| `phantom-logo-full-stacked.png` | mark above PHANTOM.AI with the tagline "Code, unmasked", 3200 x 2000: posters, social banners |

Colours: obsidian `#060608`–`#26262C`, gold `#F7E2A6` → `#D4A646` → `#9C6B1E`, ivory text `#EFE3C4`.
Wordmark: Inter Display Light, letters spaced 0.32 em. The SVG logos need Inter Display installed to show the
wordmark as designed; use the PNGs elsewhere, or have a designer convert the text to outlines.
